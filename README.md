# ভেদরগঞ্জ ইসলামিয়া চক্ষু হাসপাতাল — Website

এই ফোল্ডারটি GitHub Pages-এ সরাসরি প্রকাশ করার জন্য প্রস্তুত।

## ফাইল
- `index.html` — মূল ওয়েবসাইট
- `style.css` — ডিজাইন ও responsive CSS
- `script.js` — mobile menu, appointment WhatsApp form, year/footer
- `assets/` — আপনার দেওয়া পোস্টার ও লোগো

## GitHub Pages-এ আপলোড
1. Repository-এর `main` branch-এ এই ফাইলগুলো রাখুন।
2. Settings → Pages → Source: Deploy from a branch
3. Branch: `main` এবং folder: `/ (root)`
4. Save করুন।
5. কয়েক মিনিট পর GitHub Pages নতুন ভার্সন দেখাবে।
